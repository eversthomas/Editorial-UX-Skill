# editorial-ux-skill

> Design the work, not just the interface.

**editorial-ux-skill** ist ein universeller Open-Source-Skill für KI-Coding-Agenten. Er hilft dabei, redaktionelle und administrative Oberflächen (CMS-Backends, Verwaltungsanwendungen, Dashboards, interne Werkzeuge) zu analysieren, zu gestalten und zu verbessern, sodass Menschen damit gerne, effizient und intuitiv arbeiten.

Ein Backend ist nicht nur eine technische Verwaltungsoberfläche. Es ist ein Arbeitsplatz.

## Status

Frühe Konzeptionsphase. Es gibt noch keine lauffähige Skill-Version.

## Idee in drei Sätzen

1. **Understand the System:** Erst das vorhandene System verstehen, dann gestalten.
2. **Design for the User:** Die tatsächliche Arbeitsrealität der Benutzer bestimmt die Gestaltung.
3. **Good Work is the Measure:** Effizienz, Verständlichkeit, Barrierefreiheit und Kontrolle über die eigene Arbeit sind gleichwertig. Gerne arbeiten zeigt sich an Kontrolle, Ruhe und Souveränität.

## Geplante Befehle

Der Skill heißt wie das Repository, Befehle folgen dem Muster `/editorial-ux-skill <befehl>`:

| Befehl | Zweck |
|---|---|
| `critique` | Bestehende UX nach definierten Dimensionen bewerten |
| `discover` | System und redaktionelle Arbeitsrealität untersuchen |
| `audit` | Prüfbare Qualitätskriterien abarbeiten |
| `improve` | Kleinen Verbesserungszyklus durchführen |
| `walkthrough` | Aufgaben simuliert durchgehen |
| `design` | Lösung konzipieren und gestalten |
| `implement` | Freigegebene Gestaltung umsetzen |
| `document` | Ergebnisse und Entscheidungen dokumentieren |

Die Befehle sollen auch einzeln nutzbar sein.

## Grundsätze

- Unabhängig von CMS, Framework und KI-Anbieter
- Markdown-basiert, ohne Build-Prozess, ohne API-Schlüssel
- Keine erfundenen Benutzerbedürfnisse oder Testergebnisse
- Bewertungen unterscheiden Beobachtung, Hypothese und Annahme
